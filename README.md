# 6001CMD Coursework — Adult Census Income Dataset

Machine learning problem formulation, learning-paradigm comparison,
data-quality analysis and preprocessing strategy for the UCI Adult
(Census Income) dataset.

## Contents
- `task3_data_quality.ipynb` — missing values, duplicates, outliers,
  skewness, correlation, class imbalance, noise, inconsistency checks
- `task4_preprocessing.ipynb` — cleaning, transformation, encoding,
  feature selection, PCA, class-balancing pipeline
- `adult.csv` — dataset (from Kaggle, originally UCI)

## How to run
1. Open a notebook in Google Colab or Jupyter.
2. Make sure `adult.csv` is in the same folder.

## Dataset source
- Kaggle: https://www.kaggle.com/datasets/uciml/adult-census-income
- UCI: https://archive.ics.uci.edu/dataset/2/adult
